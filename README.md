# AMP / Rachel Woods playbook templates

Delivery repo for Khaldoon's AMP Quickstart template + playbooks extracted from [Rachel Woods YouTube](https://www.youtube.com/watch?v=Jvt3FxRKDzU).

## Files

| Path | What |
|------|------|
| `Rachel-Woods-Playbooks-from-video.xlsx` | Filled workbook (8 playbooks) emailed first |
| `templates/AMP-Quickstart-Playbook-Template.xlsx` | Empty AMP Quickstart shell |
| `templates/Rachel-Woods-Playbooks-LEAN.xlsx` | Lean filled variant |
| `templates/Rachel-Woods-Playbooks-STYLED.xlsx` | Styled filled variant |
